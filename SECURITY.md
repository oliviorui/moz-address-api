# Security policy

## Supported versions

Security fixes go to the latest release.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through [GitHub's vulnerability reporting](https://github.com/oliviorui/moz-address-api/security/advisories/new). Include the affected route or file, how to reproduce the problem and its possible impact.

## Scope

This policy covers the API code and its dependencies. To report a wrong or missing place name, open a [data correction issue](https://github.com/oliviorui/moz-address-api/issues/new/choose) instead.

# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and focus on the work. Harassment and personal attacks are not accepted.

To report a problem privately, contact the maintainer through their [GitHub profile](https://github.com/oliviorui).
